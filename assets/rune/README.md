# RUNE Logo Kit

Recommended production variants:

- `03-logo-purple-r-transparent.svg` — primary transparent logo
- `04-logo-purple-r-light-background.svg` — primary logo on light surface
- `05-logo-purple-r-dark-background.svg` — dark-mode presentation
- `08-app-icon-purple-r.svg` — app icon

Supporting variants:

- `01-logo-graphite-transparent.svg` — original monochrome mark
- `02-logo-graphite-light-background.svg` — original mark on light background
- `06-logo-white-transparent.svg` — monochrome white mark for dark surfaces
- `07-logo-white-purple-background.svg` — white mark on brand purple

Palette:

- Graphite: `#171717`
- Dark surface: `#111113`
- Purple gradient: `#A78BFA` → `#7C3AED`
- Light surface: `#F7F7F8`

All files are vector-only SVGs with no raster assets.
